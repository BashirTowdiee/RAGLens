# Known Issues

## Purpose

This document lists active known issues that support and engineering teams should reference when answering customer questions.

## Export delay after long recordings

Exports for recordings longer than three hours may take up to 20 minutes to appear in the export history page. The workaround is to wait for processing to complete and avoid starting a duplicate export.

## Calendar sync delay

Calendar events created through the external calendar integration may take up to 10 minutes to appear in the mobile app. This delay does not affect web dashboard visibility.

## Unsupported file names

Audio imports fail when the file name contains control characters or is longer than 180 characters. Users should rename the file and retry the upload.

## Resolved issues

The February 2026 issue where shared workspaces displayed stale member counts was resolved in app version 2.8.4.
