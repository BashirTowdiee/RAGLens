# Support Escalation Process

## Purpose

This process defines when support cases must be escalated beyond the frontline support team.

## Technical escalation

Cases involving repeated API failures, missing exports, data sync issues, or suspected data loss must be escalated to technical support. Technical support triages the issue and may create an engineering investigation ticket.

## Security escalation

Cases involving suspected account takeover, unauthorised access, leaked credentials, or privacy concerns must be escalated to the security queue immediately. Frontline agents must not request passwords, secrets, or private keys.

## Billing escalation

Billing disputes above 500 AUD require finance review. Repeated failed payments affecting more than 20 customers must be escalated to support operations.

## Response expectations

Security escalations require acknowledgement within 15 minutes. Technical escalations require acknowledgement within four business hours. Billing escalations require acknowledgement within one business day.
