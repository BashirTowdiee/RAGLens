# Seed Documents

This directory contains the controlled sample corpus for RAGLens development and evaluation.

The corpus is intentionally small but covers the MVP test case types:

- factual questions
- comparison questions
- temporal or versioned questions
- multi-hop questions
- no-answer questions
- citation-sensitive questions
